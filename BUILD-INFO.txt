Build commands (exactly as run, from the repository root)
  export OO_PS4_TOOLCHAIN=/home/claude/ps4-toolchain
  bash tools/ps4/fetch-toolchain.sh "$OO_PS4_TOOLCHAIN" 18
  cmake -S . -B build-ps4 -G Ninja -DCMAKE_BUILD_TYPE=Release \
        -DCMAKE_TOOLCHAIN_FILE=cmake/ps4.toolchain.cmake -DOO_PS4_TOOLCHAIN="$OO_PS4_TOOLCHAIN"
  cmake --build build-ps4 --parallel 6
  export XC_PS4_TITLE="PBOX - PS4" XC_PS4_TITLE_ID=PSBX00001 \
         XC_PS4_CONTENT_ID="IV0000-PSBX00001_00-PSBOXCLOUDGAME00" XC_PS4_VERSION=01.85
  bash tools/ps4/package.sh build-ps4 build-ps4/pkg-release
  cp "build-ps4/pkg-release/PBOX - PS4.pkg" PBOX-PS4-v1.7.15.pkg
  (the same steps as .github/workflows/build-ps4-pkg.yml; XC_PS4_VERSION = printf '%02d.%02d' 1 $((7*10+15)))

Not reproducible bit for bit
  The package is signed and encrypted by the packaging tool, and the toolchain was fetched as "latest": a rebuild
  gives a package of the same content but a different SHA256. GitHub Actions builds differ in the same way.
